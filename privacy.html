Privacy Policy

Empire Perspective app. Last updated November 2, 2026.

Empire Perspective is a private tool used only by the owner of The Empire Perspective YouTube channel to manage that channel. It is not offered to the public, and it has no other users.

What it accesses

  • The channel's own videos, thumbnails and captions, through the YouTube API Services, so it can upload private drafts and manage them.
  • The channel's own YouTube Analytics reports, so it can measure how its videos perform.
  • Only the one Google Sheet this app creates, to keep the channel's records. It cannot see other Drive files.

How the data is used

The data is used only to run this one channel: producing, measuring and improving its videos. Google user data is not sold, not used for advertising, and not used by this app to train AI models.

It is shared only with the service providers the owner uses to run the channel: Hetzner, which hosts the server where records are kept, and Anthropic, whose Claude assistant the owner uses to read analytics reports and plan videos.

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Storage and security

Sign-in tokens are stored in private files readable only by the owner's computer account and server administrator account. Analytics records are kept on those machines and in the owner's own Google Sheet.

Removing access and deleting data

Access can be removed at any time from the Google Account connections page. To ask about or request deletion of stored data, use the contact below. Stored analytics are removed on request.

Services used

This app uses YouTube API Services. By using it you are bound by the YouTube Terms of Service, and your data is handled under the Google Privacy Policy.
